Project Description:

- This project will model basic drone movement in 2D space using physics equations for thrust and gravity.

- Description of components, features, outputs, elements (classes): The program will ask the user to input the name, weight, velocity, time of travel, and the direction of movement in degrees (standard position). Optionally, the user may also give the acceleration. This information will then be used for the *class Drone* which will have the methods *Drone Travel*, *Modify Drone*, and lastly, *Drone Math*. The first method will calculate how far the drone will travel, the second will enable the user to change the previous variables stated, and the last will calculate the instantaneous details of the drone at a user-given interval, intended to be used when acceleration is inputted by the user.

- The project's target demographic are high school students who currently study Physics.

Goals:

What our group wants as long term outcomes from this project are for users to familiarize themselves with or learn basic physics concepts as well as enable future advanced object/vehicle movement simulations to use this model as a basis or guide.

Objective 1: Implement 2D kinematics and physics calculation. Develope the Drone class using proper progrsmming to compute 2D displacement, thrust, gravity and the instantaneous motions given by the user.

Objective 2: Build an interactive user input system. Create a user-friendly interphase where students can input and modify the drone’s variables to their desired parameters.

Objective 3: Polish making an educational physics tool. Design the simulation to properly emulate and visualize the physics of basic projectile movement and vehical motion for high school students.
