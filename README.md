Project Description:

- This project will model basic drone movement in 2D space using physics equations for thrust and gravity.

- <Description of components, features, outputs, elements (classes)> The program will ask the user to input the name, weight, velocity, time of travel, and the direction of movement in degrees (standard position). Optionally, the user may also give the acceleration. This information will then be used for the *class Drone* which will have the methods *Drone Travel*, *Modify Drone*, and lastly, *Drone Math*. The first method will calculate how far the drone will travel, the second will enable the user to change the previous variables stated, and the last will calculate the instantaneous details of the drone at a user-given interval, intended to be used when acceleration is inputted by the user.
